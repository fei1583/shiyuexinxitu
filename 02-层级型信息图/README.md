# 层级型信息图

以从属、包含、等级或分层关系组织信息的信息图。重点表达上下位关系、层级深度、分支结构与权责/规模差异。

## 常见表现形式
- 组织结构图
- 树状层级图
- 金字塔图
- 分类层级图
- 旭日图

## 本类案例
案例分析报告存放于「案例分析报告」，图片存放于「案例图片」。每新增案例，请补充本页对应的类型归纳，并更新本目录的《层级型信息图概念及说明.md》与《案例索引.md》。
