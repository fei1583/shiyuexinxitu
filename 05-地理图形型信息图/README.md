# 地理图形型信息图

## 类型概念
以地理位置、区域边界、空间邻接、分布或路径作为主要组织语法。需区分定位地图和专题统计地图。

## 案例研究
- 001｜Plan Showing the Ascertained Deaths from Cholera：Wellcome Collection原始藏品页提供全尺寸图，标记Public Domain Mark；图片/Excel留待手动上传。
- 002｜Ageing in Hong Kong：已归档地图模块，作品主分类为混合型；地图编号承担18区索引，不代表排名。
