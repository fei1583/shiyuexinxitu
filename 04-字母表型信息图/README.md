# 字母表型信息图

以字母、字符或固定符号序列作为组织骨架的信息图。可按字母顺序逐项解释概念、对象或知识点。

## 常见表现形式
- A-Z知识图谱
- 字母索引图
- 首字母分类图
- 字符解释图
- 插画联想字母表
