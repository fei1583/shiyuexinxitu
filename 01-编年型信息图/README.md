# 编年型信息图

以时间顺序、历史时期或阶段演进为核心组织原则的信息图。既包括连续时间轴，也包括按编号或分区组织的历史阶段分章型信息图。

## 常见表现形式
- 时间轴
- 年表
- 历史演进图
- 历史阶段分章图
- 项目进度时间线
- 生命周期图
