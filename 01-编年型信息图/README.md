# 编年型信息图

以时间顺序、历史时期或阶段演进为核心组织原则的信息图。包括连续时间轴、多行折返时间轴、年表及历史阶段分章图。

## 已收录案例
- **001｜The history of CATS in China**：四阶段历史分章，含十二生肖传说专题。[案例报告](./案例分析报告/001-The-history-of-CATS-in-China-编年型信息图案例分析报告.md)
- **002｜From Peter to Leo XIV**：从Peter至Leo XIV的教皇序列，多行横向时间区块折返排列。[案例报告](./案例分析报告/002-From-Peter-to-Leo-XIV-编年型信息图案例分析报告.md)
