## 案例维护原则

新增案例时，应同时补充对应案例分析报告、示例图及分类索引，并回顾更新所属类别的“概念及说明”总文档。分析应尽可能说明信息组织方式、数据结构、统计图形应用、视觉编码、信息框架与叙事框架。

## 目录约定

- 图片统一放入对应的“示例图”或“案例图片”目录，文件名注明案例名称与来源。
- 每个案例单独建立 Markdown 分析报告。
- 暂无案例的目录以说明文档和 `.gitkeep` 保留结构。
- 引用外部案例时记录原始链接、作者/机构及访问日期，并尊重版权。
