## 案例入库原则
- 每个案例指定唯一主分类；其他图形结构作为辅助分类交叉引用。
- 每个作品有独立案例分析报告；类型概念总文档和子类03—08研究文档随案例更新。
- 用户负责上传原图和Excel；仓库文档负责分类、分析、索引、来源和数据质量说明。
- 不以占位文件、候选来源或空报告计入正式案例数量。
- 无原始数据时只可制作明确标注的图像转录表，不得伪造作者原始数据。
