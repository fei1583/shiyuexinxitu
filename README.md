# 信息图形研究库

本仓库采用分层分类：**基础信息组织逻辑 → 常见表现形式 → 专项设计方法 → 统计图形 → 视觉组织原则 → 主题设计流程**。

| 编号 | 目录 | 定位 |
|---|---|---|
| 01 | [信息图形数据逻辑](./01-信息图形数据逻辑/README.md) | 唯一基础类型学：编年、层级、编目、字母表、地理五种逻辑 |
| 02 | [信息图形类型案例](./02-信息图形类型案例/README.md) | 常见表现形式标签，不是第二套基础类型学 |
| 03 | [ISOTYPE 专项研究](./03-ISOTYPE信息图/README.md) | 独立的图符语言与信息转译方法研究 |
| 04 | [统计图形分析](./04-统计图形分析/README.md) | 数据结构、统计图表选择、计算与视觉编码 |
| 05 | [Gestalt 视觉组织原则](./05-Gestalt视觉组织原则/README.md) | 视觉知觉、分组与组织原则研究 |
| 06 | [主题信息图形设计](./06-XX（待定）主题信息图形设计/README.md) | 调研、数据、叙事、视觉编码和实施流程 |
| — | [现有图形案例资产库](./各类常用信息图形案例库/README.md) | 保留既有图片、Excel 与分析报告的存放位置 |

每个作品只指定一个基础主分类；表现形式、内容载体、视觉风格、统计图形和基础设计方法分别记录。ISOTYPE 不属于第六种基础类型，也不作为普通表现形式标签。既有资产不因分类调整而删除或重复复制。不得伪造数据、来源、版权状态或案例结论。
