## 统一归档规则

- 五类信息图形理论文档及其对应案例目录统一置于「01-信息图形数据逻辑」。
- 每个独立作品只设一个主分类；关系图、地图、时间轴等可作为辅助分类交叉引用。
- 「信息图形类型案例」作为历史专题资料保留在数据逻辑目录内；新增案例优先归入五类主分类。
- 图片、Excel/CSV与分析报告使用相同案例编号；正式文件名应可读，不使用随机上传文件名。
- 不设置独立的「待分类素材」暂存目录；新增素材应在确认归属后直接放入相应案例目录，无法确认的内容在对应目录的说明文档中注明。
- 不伪造原始数据、作者、来源或版权信息。
