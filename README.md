## 强制文档结构规范
每个主分类必须有类型概念总文档、案例索引和逐案分析报告；每个常用图形子类必须有00概念总文档、01示例图、02逐案分析报告及03—08六项研究总文档。完整要求见[贡献与维护规范](./CONTRIBUTING.md)。

## 归档规则
- 每个案例只指定一个主分类，辅助分类通过链接交叉引用。
- 图片、Excel、报告采用统一案例编号。
- 不用文件名代替分析；不以低清图片推测姓名、年份、图例或统计值。
- 用户负责上传原图和工作簿；仓库维护负责归档、索引、文档及分类分析。
