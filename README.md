## 统一归档规则

- 每个独立作品只能有一个主分类；关系图、地图、时间轴等可作为辅助分类交叉引用。
- 新增案例优先进入五类主分类；常用图形案例库用于补充分析视角，不再建立第三套独立案例。
- 历史专题目录仅保留既有资料，不作为新增案例的默认入库位置。
- 图片、Excel/CSV与分析报告使用相同案例编号；正式文件名应可读，不使用随机上传文件名。
- 未识别素材先放入「00-待分类素材」，识别后再归入唯一主分类，并更新总索引。
- 不删除来源不明或暂时无法识别的原始文件；不伪造原始数据、作者、来源或版权信息。
