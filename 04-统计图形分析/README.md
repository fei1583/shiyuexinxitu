# 04｜统计图形分析

研究信息图形使用的统计图形及其数据要求，重点包括源数据结构、字段类型、数据转换、聚合计算、图表选择、视觉编码和适用边界。

## 研究模块

- 数据结构与测量尺度；
- 筛选、排序、聚合、比例、变化率与不确定性；
- 比较、分布、构成、关系、时间序列和空间数据的图形选择；
- 位置、长度、角度、面积、颜色、形状与连接等视觉编码；
- 输入字段、计算过程、图表选择理由和限制的可复核记录。

统计图形是视觉表达工具，不等于信息组织逻辑，也不自动决定作品的基础主分类。案例先按 01 五种逻辑分类，再通过 02 和本目录记录表现形式及统计方法。本目录当前为研究框架入口，不将尚未建立的分析文档标记为已完成。
