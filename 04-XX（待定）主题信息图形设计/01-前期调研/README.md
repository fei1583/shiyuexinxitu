# 01 前期调研

## 目标
在设计之前明确“为什么做、为谁做、要回答什么问题”，避免主题过大或目标模糊。

## 调研任务
- 选题背景与现实意义
- 目标受众、使用场景与读者已有知识
- 核心研究问题、次级问题与预期结论边界
- 时间、地域、对象和统计口径范围
- 已有信息图形、研究报告和相关设计案例
- 可获得的数据、版权限制与实施条件
