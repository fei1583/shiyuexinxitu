# 03 数据搜集

## 数据来源类型

### 公共数据集
政府开放数据、国际组织数据库、科研机构数据、开放 API、公共统计资料等。记录发布机构、数据集名称、下载地址、发布日期、更新时间、许可协议和统计口径。

### 文本文献
学术论文、专著、政府报告、新闻报道、档案、网页和访谈文本。记录作者/机构、标题、出版时间、页码或段落、URL/DOI及引用信息。

### 自建数据集
通过观察、问卷、访谈、人工编码、图像转录、现场采集或程序化采集建立。记录采集方法、样本范围、字段定义、采集时间、编码者和质量控制方式。

## 搜集原则
- 优先使用原始来源和权威机构资料。
- 记录访问日期和版本；网页可能变化时保存必要的本地副本或引用摘录。
- 不把二手转述当作原始统计数据。
- 记录缺失值、估读值、推算值和人工判断，不将它们伪装成精确事实。
- 核查授权、隐私和再利用许可。

## 阶段产出
