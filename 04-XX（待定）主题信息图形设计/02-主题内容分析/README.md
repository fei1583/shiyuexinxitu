# 02 主题内容分析

## 目标
将调研主题拆解为信息单元、关系和潜在叙事，并与大模型进行多轮讨论，提出可验证的类型与设计标签建议。

## 与大模型讨论的重点

1. 主题的核心对象、关键概念、时间/空间维度和对象之间的关系。
2. 信息组织逻辑：是否适合编年型、编目型、层级型、地理图形型、比较型、关系型或混合结构。
3. 表现形式：是否需要词云图、文字型信息图、照片型信息图、地图、流程图、统计图形、图解或符号系统。
4. 视觉风格：照片、插画、手绘、扁平、极简、复古等风格是否符合内容和受众。
5. 基础设计方法：是否适合 ISOTYPE、图标系统、模块化符号、网格系统等方法。

## 分类维度必须分开

| 维度 | 判断内容 | 例子 |
|---|---|---|
| 信息组织/叙事类型 | 信息按什么逻辑组织 | 编年型、编目型、层级型 |
| 图形表现形式 | 用什么图形承载信息 | 词云图、地图、流程图、统计图形 |
| 内容载体 | 使用什么素材 | 文字、照片、插画、图标 |
| 视觉风格 | 画面呈现方式 | 照片风格、扁平风格、手绘风格 |
| 基础设计方法 | 用什么方法组织视觉语言 | ISOTYPE、模块化符号系统 |

## 推荐的大模型讨论提示词

“请先分析以下主题的研究问题、信息对象、数据关系和目标受众。不要直接替我决定一种图形。请分别从信息组织/叙事类型、图形表现形式、内容载体、视觉风格、基础设计方法五个维度提出候选方案；说明每个方案适用的内容、所需数据、优点、风险和证据缺口。最后给出一个主方案和一个备选方案，并说明选择依据。主题资料如下：……”
