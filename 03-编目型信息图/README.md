# 编目型信息图

以并列条目、清单、目录或类别集合组织信息的信息图。重点是条目识别、分类依据、检索线索与比较维度。

## 常见表现形式
- 清单图
- 图鉴
- 目录式信息图
- 卡片矩阵
- 分类索引图

## 本类案例
案例分析报告存放于「案例分析报告」，图片存放于「案例图片」。每新增案例，请补充本页对应的类型归纳，并更新本目录的《编目型信息图概念及说明.md》与《案例索引.md》。
