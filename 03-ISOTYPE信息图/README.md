# 03｜ISOTYPE 信息图专项研究

ISOTYPE（International System of Typographic Picture Education）是独立的设计方法与历史专题，不是第六种基础信息组织逻辑，也不是 02 中的普通表现形式标签。

## 研究范围

- 历史脉络、代表人物、原始文献与档案；
- 图符语言、标准化图形单位与视觉语法；
- 数量信息的图像化转译、重复单位和统计表达；
- 区分历史原作、确证采用该方法的现代作品，以及仅受其风格启发的作品；
- 面向具体主题的数据转译与设计实践。

## 与其他目录的关系

01 为案例确定唯一基础主分类；02 记录实际表现形式；04 研究统计图形与数据；05 研究视觉分组与知觉；06 可在视觉编码阶段引用 ISOTYPE 方法。

研究记录应注明文献出处、图符单位、数据口径、取整规则与版权状态。没有来源证据时不得标注为 ISOTYPE 原作或已验证案例。原有 [ISOTYPE 基础设计方法说明](../各类常用信息图形案例库/00-基础设计方法标签/ISOTYPE/README.md) 保留为历史入口。
