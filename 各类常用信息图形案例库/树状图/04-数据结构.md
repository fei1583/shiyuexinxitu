# 数据结构

## 树状数据模型
| 字段 | 含义 |
|---|---|
| node_id | 节点唯一标识 |
| parent_id | 父节点标识 |
| depth | 层级深度 |
| sibling_order | 同层排序 |
| label | 节点名称 |

严格树结构中每个非根节点只有一个parent_id。若同一实体有多个亲属关联，应另建关系边表，不能强行塞进单一parent_id。

## 案例001
工作簿列出7个世代/关系层级（高祖/曾祖、祖父母、父母、同辈、本人及配偶、子女、孙辈），并另列父系/母系两种谱系侧别。称谓词汇表47条；关系结构表9条；读图说明14条；来源元数据10项。

## 推荐混合模型
采用层级节点表 + 多关系边表 + 称谓词典。这样保留树状阅读结构，同时能表达配偶、姻亲和旁系连接。
