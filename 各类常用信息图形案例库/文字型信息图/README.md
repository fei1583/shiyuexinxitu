# 文字型信息图案例库

本目录用于收录以文字、字符、字母、词条或语言单元为主要组织结构的信息图。

## 已收录案例
- **001｜Illustrated Alphabet A–Z**：字母表型、插画联想、大小写配对及数字附属模块。专项报告见[案例分析报告](./02-分析报告/001-Illustrated-Alphabet-AZ-案例分析报告.md)。

## 目录规范
- 示例图放入「01-示例图」，由用户自行上传。
- 每个案例在「02-分析报告」中单独建立报告。
- 本目录的六份研究文档分别维护类型学分类、数据结构、统计图形应用、视觉编码、信息框架和叙事框架；新增案例时更新相关条目。
- 字母表型信息图的专项总文档另见仓库根目录的「04-字母表型信息图」。
