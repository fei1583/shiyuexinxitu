# 文字型信息图｜案例分析报告目录

本目录按作品独立保存分析报告。报告区分已归档素材案例与基于公开来源建立的研究案例；后者的图片/Excel仍需手动归档后复核，不计为已完成素材案例。

- [001｜Illustrated Alphabet A–Z](./001-Illustrated-Alphabet-AZ-案例分析报告.md) — 字母表型主分类的文字型辅助案例
- [002｜STABILO Alphabet Poster](./002-STABILO-Alphabet-Poster-文字型信息图案例分析报告.md) — 已建立官方PDF来源研究报告；图片/工作簿待手动上传

每个报告需包含原始来源、图形结构、数据字段、统计图形应用、视觉编码、信息框架、叙事路径和证据限制。
