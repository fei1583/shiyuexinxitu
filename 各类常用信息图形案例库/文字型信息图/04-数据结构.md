# 数据结构

## 数据实体与字段
| 字段 | 类型 | 含义 | 是否必需 | 示例 |
|---|---|---|---|---|
| id | string | 唯一标识 | 是 | item-001 |
| label | string | 展示名称 | 是 | 示例条目 |
| value | number/string | 数值或文本内容 | 视情况 | 12 |
| category | string | 分类维度 | 否 | 类别A |
| relation | string | 关系/连接 | 否 | parent-of |

## 案例001：Illustrated Alphabet A–Z
工作簿包含5张表：字母索引、字母插图对象、数字0—9、图形结构拆解、数据口径说明。
- 字母实体：26条；字段包括序号、大写、小写、英文/中文名称、版面行序、视觉主色。
- 插画对象实体：117条；一个对象一行，含对象编号、所属字母、对象名称、类别、识别依据、置信度及备注。
- 数字实体：10条；含数字字符、图标观察、数量编码可确认性。
- 结构观察：主题、版式、颜色、辅助线、大小写标注、署名与来源状态。

## 数据组织方式
建议使用字符主表（26行）与关联对象表（每对象一行）建立一对多关系；数字区独立建表。图像资产和词条数据分开管理。

## 数据质量与转换
- 工作簿记录117条对象，识别置信度：高74、中36、低7。
- 对象名称存在不确定性时保留置信度和说明，不将推测转为确定事实。
- 多对象必须拆分为多行；每列只保存一个字段。
- 数字2—9附近可观察到相应数量的小图标，但图中未解释规则，记录为视觉计数观察而非已证实语义。
- 原始来源和发布日期未能从图片确认。
