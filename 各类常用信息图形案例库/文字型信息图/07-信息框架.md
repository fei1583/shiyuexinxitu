# 信息框架

## 核心问题
该图形希望读者理解或完成什么？

## 信息层级
1. 主题/结论
2. 主要分组或关键维度
3. 数据、事实与例证
4. 来源、口径与注释

## 案例001：Illustrated Alphabet A–Z
- **主题层：** 英文字母和数字识别。
- **主序列：** A—Z，共26个字母。
- **字符层：** 每个字母的大写与小写形式。
- **联想层：** 字母周围的动物、食物、植物、人物、器物等插画对象。
- **附属模块：** 数字0—9及其上方小图标。
- **版面组织：** 横向分行；前六行每行4个字母，末行Y、Z及数字区。
- **来源层：** 底部可辨认Renard Roux标识；出版日期、完整原始网页未确认。
