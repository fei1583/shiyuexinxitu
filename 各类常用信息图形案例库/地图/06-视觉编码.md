# 视觉编码｜地图

| 变量 | 可能作用 | 核验要点 |
|---|---|---|
| 位置 | 空间定位 | 是否提供坐标/边界 |
| 点/圆大小 | 位置或数量规模 | 是否给出比例公式 |
| 颜色 | 分类或数值分级 | 图例是否可读 |
| 编号 | 地图与清单配对 | 不自动代表排名 |
| 连线 | 标签与位置匹配/流向 | 是否有方向箭头 |
| 区域形状 | 地理单元 | 边界来源与精度 |

## 案例
Power Centers使用曲线连接标签和都会区点位，圆点大小表达量级但比例公式不明。Ageing使用18区编号与右侧行政区清单配对，地图灰色底图不表示人口密度。
