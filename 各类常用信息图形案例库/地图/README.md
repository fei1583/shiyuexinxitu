# 地图案例库

本目录用于收录地图的代表性示例，并从类型学、数据结构、统计图形应用、视觉编码、信息框架和叙事框架等维度持续研究。

- 示例图放入「01-示例图」。
- 每个案例在「02-分析报告」中单独建立报告。
- 案例积累后，持续修订本目录的六份研究文档。
