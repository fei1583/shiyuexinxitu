# 数据结构

## 数据实体与字段
地图型信息图形通常以地理单元作为实体，字段可包括：
| 字段 | 类型 | 含义 | 是否必需 | 示例 |
|---|---|---|---|---|
| geo_id | string | 地理单元唯一编号 | 是 | district-01 |
| geo_name | string | 地理单元名称 | 是 | Eastern |
| geo_level | string | 地理层级 | 视情况 | 行政区 |
| value | number | 绑定指标数值 | 视情况 | 136300 |
| unit | string | 数值单位 | 视情况 | 人 |
| year | integer | 统计年份 | 视情况 | 2025 |
| geometry/coordinates | geometry/array | 地理边界或坐标 | 视地图类型 | 本案例未提供 |
| category | string | 地区组别或类别 | 否 | Hong Kong Island |

## 案例 002 的数据结构
《Ageing in Hong Kong》可拆分为以下实体：
- 行政区实体：18个香港行政区，含编号、英文名、中文名和地区组别。
- 指标实体：各区65岁及以上人口数（2025年，单位：人）。
- 人口概览实体：香港65岁及以上人口1,975,220人（26%）及65岁以下人口5,621,780人（74%），年份为2026；老年人口口径排除外籍家庭佣工。
- 占比实体：图中给出区级老年人口占比范围17.4%—27.1%，并标出东区27.1%、黄大仙区26.9%。
- 空间实体：18区地图示意底图；现有资料没有边界矢量、经纬度或投影参数。

## 数据质量与转换
- 2026年整体人口概览与2025年区级数据属于不同统计年份，须分开标注。
- 人口总量、占比和支出数据不得混用单位。
- 2025年区级人口清单是人口数量，不是人口占比。
- 地图仅作空间定位，不能从图像反推精确边界或坐标。
- 计算值须与原图标注值区分。例如：1,975,220 + 5,621,780 = 7,597,000，为根据两年龄组相加得到的计算值，不是图中单独标注的总人口数字。

## 示例数据
案例 002 的区级人口字段样例：Eastern（东区），2025年65岁及以上人口136,300人；Sha Tin（沙田区）167,400人。数据来源为用户提供的案例拆解工作簿，统计年份和口径按工作簿记录。
