# 对比图案例库

本目录用于收录对比图的代表性示例，并从类型学、数据结构、统计图形应用、视觉编码、信息框架和叙事框架等维度持续研究。

## 已收录
- **003｜Comparing Population Pyramids**：多国家/地区人口金字塔横向比较。
- **004｜China–India Population Pyramid (2017)**：中国与印度2017年人口金字塔对比。

示例图位于「01-示例图」，配套工作簿位于「案例数据」。请注意，2017年图片与其他年份的人口金字塔案例不可混用。
- 每个案例在「02-分析报告」中单独建立报告。
- 案例积累后，持续修订本目录的六份研究文档。
