# 结构图｜数据结构

## 核心定义与方法
建筑平面、剖面结构、爆炸装配、系统架构、部件组成、组织结构。住宅平面图无尺寸/比例尺/方位，不可当施工测量图。

## 研究与入库规范
- 每个独立作品建立单独案例分析报告；本文件用于归纳该子类的共性、差异与方法，不替代逐案报告。
- 记录原图标题、作者/机构、发布日期、来源URL、版权/许可、数据来源和访问日期。
- 每列一个字段、每行一个实体或观测；单位、时间范围、分母、分类口径单列保存。
- 将原始来源数据、图像转录、估读值和分析者推断分开标注；不确定项标注“未确认”。
- 不将装饰性位置/颜色/大小解释为数据编码，除非图例或来源能证明。

## 逐案更新要求
新案例入库后，根据其证据更新本文件的子类型、字段模型、统计适用性、视觉编码、信息层级和叙事路径；同时保留反例，不把单一案例规律泛化为全类型规则。

## 质量检查
| 检查项 | 验收标准 |
|---|---|
| 类型判定 | 主类与辅助类有明确依据 |
| 数据 | 单位、时间、分母、来源可追溯 |
| 视觉 | 每个编码含义有图例或证据 |
| 统计 | 说明统计图用途或明确未使用 |
| 信息 | 主题、分组、注释、来源齐全 |
| 叙事 | 阅读顺序与结论边界清楚 |
