本库按具体图形表现形式收录案例。每个子类统一包含八项研究结构：01示例图、02分析报告、03信息图形类型学分类、04数据结构、05统计图形应用、06视觉编码、07信息框架、08叙事框架；配套Excel另设「案例数据」。

## 基础设计方法标签

基础设计方法与图形类型不同，可以跨多个子类使用，统一在本库单独管理：
- [基础设计方法标签](./00-基础设计方法标签/README.md)

## 归档规则
主分类只指定一个，辅助分类可多项；同一原始文件可在多个分类目录中引用同一Git对象，不重复制作二进制副本。图片和工作簿使用相同案例编号。证据不足时标记待补/待核实，不以推测填补原图数据。

## 每个子类的标准目录
```text
子类名称/
├── 00-图形类型概念及说明.md
├── 01-示例图/
│   ├── README.md
│   └── 案例原图文件
├── 02-分析报告/
│   ├── README.md
│   └── 案例001-子类案例分析报告.md
├── 03-信息图形类型学分类.md
├── 04-数据结构.md
├── 05-统计图形应用.md
├── 06-视觉编码.md
├── 07-信息框架.md
├── 08-叙事框架.md
└── 案例数据/
    ├── README.md
    └── 案例工作簿.xlsx（如有）
```

注意：案例报告按作品逐一新增，不得把两个作品合并为一份报告；00与03—08是随案例积累持续更新的子类级总文档。案例数量只依据已归档原图及对应独立分析报告统计。
