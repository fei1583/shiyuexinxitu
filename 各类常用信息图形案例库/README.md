# 现有图形案例资产库

本目录保留仓库既有图形案例图片、Excel 工作簿及逐类研究文档，是实际资产的存放位置，不再承担顶层分类体系的定义工作。

## 与顶层分类的关系

- [01 信息图形数据逻辑](../01-信息图形数据逻辑/README.md)：每个案例的唯一基础主分类。
- [02 信息图形类型案例](../02-信息图形类型案例/README.md)：17 种表现形式标签及交叉检索。
- [03 ISOTYPE 专项](../03-ISOTYPE信息图/README.md)：跨类型设计方法研究。
- [04 统计图形分析](../04-统计图形分析/README.md)：数据图表方法。
- [05 Gestalt 视觉组织原则](../05-Gestalt视觉组织原则/README.md)：视觉分组与知觉原则。

既有子库：关系图、树状图、流程图、结构图、对比图、地图、文字型信息图、词云图、时间轴图和其他。原有 [ISOTYPE 说明](./00-基础设计方法标签/ISOTYPE/README.md) 保留为历史入口；正式专项入口为仓库根目录的 03。

既有图片、工作簿和报告不因分类体系调整而删除或重复复制。每个作品应有唯一案例编号和唯一基础主分类；表现形式、内容载体、视觉风格、统计图形及设计方法作为独立字段记录。证据不足时标记待核实。
