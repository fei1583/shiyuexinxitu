## 归档规则
主分类只指定一个，辅助分类可多项；同一原始文件可在多个分类目录中引用同一Git对象，不重复制作二进制副本。图片和工作簿使用相同案例编号。证据不足时标记待补/待核实，不以推测填补原图数据。
