# 词云图案例库

本目录用于收录词云图的代表性示例，并从类型学、数据结构、统计图形应用、视觉编码、信息框架和叙事框架等维度持续研究。

## 已收录
- **001｜Word Cloud for Meeting**：会议讨论词云案例，配套数据工作簿已归档。
- **002｜Context-Preserving Dynamic Word Cloud**：上下文保持动态词云案例，配套数据工作簿已归档。
- **003｜Inspiring / Good Word Cloud**：积极词汇主题词云示例，当前仅归档图片，未发现对应数据工作簿。

- 示例图放入「01-示例图」。
- 每个案例在「02-分析报告」中单独建立报告。
- 案例数据放入「案例数据」目录；没有配套数据时不创建空工作簿。
