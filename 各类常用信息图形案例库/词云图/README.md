# 词云图案例库

本目录用于收录词云图的代表性示例，并从类型学、数据结构、统计图形应用、视觉编码、信息框架和叙事框架等维度持续研究。

- 示例图放入「01-示例图」。
- 每个案例在「02-分析报告」中单独建立报告。
- 案例积累后，持续修订本目录的六份研究文档。

- 03—08｜本类类型学、数据结构、统计图形应用、视觉编码、信息框架、叙事框架总文档（见本目录同名文件）
- [案例分析报告统一模板](../../案例分析报告模板.md)
