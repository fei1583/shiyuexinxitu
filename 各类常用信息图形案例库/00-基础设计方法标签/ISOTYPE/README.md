# ISOTYPE｜基础设计方法标签

## 标签定位

**ISOTYPE 不作为一种信息图形类型归类，而作为一种基础设计方法与视觉表达系统单独标记。**

ISOTYPE（International System of Typographic Picture Education，国际图画教育系统）以标准化图像符号、重复的图形单位及其组织规则，将数量、社会事实和复杂信息转化为可读的视觉表达。它既涉及符号设计，也涉及信息组织、数量表达和视觉叙事。

## 为什么单独设标签

- **分类层级不同**：编年型、层级型、编目型、地理图形型等描述信息组织或叙事结构；ISOTYPE 描述的是一套视觉传达方法。
- **可以跨类型使用**：ISOTYPE 方法可以服务于时间、比较、地理、分类、社会统计等不同主题，不对应唯一版式。
- **不仅是图标装饰**：图形单位的含义、数量关系、重复规则、图例和阅读顺序共同构成表达系统。

## 标签使用规则

当案例或设计项目使用了下列方法时，可以添加 ISOTYPE 标签：

1. 使用具有稳定语义的图画符号代表人物、物件、事件或类别。
2. 通过重复符号单位表达数量或规模，并明确单位代表的数值。
3. 通过符号的组合、排列、分组或变化表达比较、比例、分类或关系。
4. 配有清晰图例、单位说明和阅读规则，使读者能够解码。

仅仅使用插画、图标或装饰性小人，不足以标记为 ISOTYPE。

## 与信息图形类型的关系

| 维度 | 示例 | 回答的问题 |
|---|---|---|
| 信息组织/叙事类型 | 编年型、编目型、层级型、地理图形型 | 信息如何组织？ |
| 图形表现形式 | 词云图、地图、流程图、统计图形、照片型表达 | 信息以什么形式呈现？ |
| 基础设计方法 | ISOTYPE、图标系统、网格系统、模块化符号 | 采用什么设计方法表达？ |
| 视觉风格 | 扁平、照片、手绘、复古、极简 | 画面呈现出什么风格？ |

这些维度可以交叉组合，不应相互替代。

## 案例记录建议

使用该标签时，建议记录：符号代表对象、单个符号代表的数量、符号是否标准化、排列规则、图例、颜色编码、是否存在比例失真，以及读者如何从符号还原数据。
