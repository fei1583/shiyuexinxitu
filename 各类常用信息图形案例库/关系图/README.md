# 关系图案例库

本目录收录以节点和关系连线表达实体关联的信息图。

## 已收录案例
- **001｜Family tree: a guide to the Chinese kinship system**：亲属关系网络图。以本人/配偶为中心，区分父系、母系、世代、旁系及姻亲。详见[关系图案例分析报告](./02-分析报告/001-Chinese-Kinship-System-关系图案例分析报告.md)。

## 目录规范
- 原图放入「01-示例图」。
- 每个案例在「02-分析报告」中单独建立报告。
- 六份研究文档随新案例更新：类型学分类、数据结构、统计图形应用、视觉编码、信息框架、叙事框架。
- 本案例同时关联「树状图」目录，但关系图为主分类，因为图中存在姻亲、配偶及跨分支关系，非严格树结构。
- 图片与Excel原文件需由用户上传到对应案例文件夹；当前文档提交不等于二进制文件已入库。
