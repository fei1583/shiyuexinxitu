# 数据结构

## 核心实体与字段
| 实体 | 字段 | 含义 |
|---|---|---|
| Node | node_id、label、node_type | 人物/角色/概念节点 |
| Edge | edge_id、source_id、target_id、relation_type | 关系边及其类型 |
| Attribute | gender、seniority、lineage_side、generation | 节点或关系属性 |
| Term | term_id、English_relation、local_term、romanisation | 关系称谓及多语标签 |
| Source | source_id、publisher、date、author、url | 来源元数据 |

## 案例001工作簿结构
4张表：
- `01_称谓词汇表`：47条称谓记录，含英文亲属关系、粤语汉字称谓、粤拼/图中罗马音、亲属类别、父系/母系、长幼/性别区分、标注语言及识读备注。
- `02_家族树关系结构`：9条关系结构记录，含世代层级、英文分区、关系对象、方向/来源、谱系侧别、颜色与备注。
- `03_读图规则与使用说明`：14条规则和说明。
- `04_来源与元数据`：10项来源及出版信息。

## 建议关系模型
关系边独立成行，字段至少包括source_id、target_id、relation_type、lineage_side、generation_delta、seniority、gender_condition。称谓词条与关系边分离，允许同一关系条件映射到一个或多个地方称谓。

## 数据质量提示
- 以上行数为工作簿记录数，不是家庭成员或人口样本数。
- K027记录Son-in-law对应“新抱”，K028记录Daughter-in-law对应“女婿”，英文/中文配对疑似需要核对；本库忠实保留原始工作簿，不擅自改写。
- “依分支”“按原图记录”等限定应随数据保留。
- 原始文章URL未包含在工作簿中。
