# 统计图形应用

## 关系图是否属于统计图
关系图主要表达节点和关系，不必然呈现统计量。连线数量、节点数量或节点位置不能在没有明确定义时解释为频率、重要性或强度。

## 可结合的统计表达
| 分析问题 | 可结合图形 | 前提 |
|---|---|---|
| 不同亲属类别的称谓条目数 | 条形图 | 先定义类别口径 |
| 不同代际称谓数量 | 条形图/点图 | 代际归属一致且可核验 |
| 父系与母系条目数量对照 | 分组条形图 | 记录的谱系侧别可比较 |
| 关系网络结构特征 | 网络指标摘要 | 节点/边定义完整，避免将示意图当真实样本 |
