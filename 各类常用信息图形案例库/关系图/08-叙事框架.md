# 叙事框架

## 案例001叙事路径：以本人为中心的关系查询
1. 读者从YOU / YOUR SPOUSE中心节点进入。
2. 根据目标亲属选择父系或母系分支。
3. 沿连线向上、向下或向旁系追踪关系路径。
4. 结合世代、性别、长幼与姻亲条件辨认具体关系。
5. 查阅繁体中文称谓与罗马拼写。
6. 使用中央“How to read this graphic / How to use this tool”说明及示例核对路径。

## 叙事性质
属于查询/探索型关系叙事，而不是时间顺序叙事。读者可从中心向多个方向探索，路径并非唯一线性顺序。

## 叙事检查
密集连线应保持可追踪；颜色语义必须有图例；对地区差异和称谓不确定性保留注释。
