# 数据结构｜时间轴图

## 通用实体
| 实体 | 字段 |
|---|---|
| Event | event_id、sequence_no、event_name、description、subject、source_id |
| Period | period_id、period_name、start_date/year、end_date/year、precision |
| Interval | interval_id、start、end、duration、duration_unit |
| Subject | subject_id、subject_name、subject_type |
| Source | source_id、publisher、author、date、url、confidence |

## 人物任期序列扩展字段
pontiff_id、papal_name_original、name_translation、reign_start、reign_end、century、biographical_note、portrait_present、portrait_match_status、legend_category、highlight_label。

## 案例工作簿盘点
- Cats in China：6张表、98条记录，包含阶段、历史事实、生肖、传说、图文元数据、数值与时间。
- From Peter to Leo XIV：6张表、59条记录，包含元数据、可辨识人物事实、时间轴字段模板、视觉编码、识别质量、来源边界。

## 质量规则
原始时间文本与标准化字段分开；估计年份保留精度；父子时期不强制互斥；无法识别的姓名、年份和图例留空并标记待核验。
