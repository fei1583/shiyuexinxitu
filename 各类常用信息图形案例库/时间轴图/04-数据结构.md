# 数据结构

## 数据实体与字段
| 实体 | 字段 | 含义 |
|---|---|---|
| Period | period_id、period_name、start_year、end_year、display_range、precision | 历史时期及时间范围 |
| Event | event_id、period_id、event_name、description、topic_category、subject | 事件及所属时期 |
| Sequence | stage_number、display_order、parent_period_id | 分章顺序与层级 |
| NumericDatum | metric、value、unit、value_type、source_label | 与事件有关的数值 |
| Supplement | supplement_id、topic、narrative_order、participants、outcome | 生肖传说等补充专题 |
| Source | publisher、author、source_title、url、source_note | 来源元数据 |

## 案例001工作簿结构
Excel共6张表、108条数据记录（不含表头）：
- `01_历史阶段`：8条，含四个宏观阶段及朝代子阶段。
- `02_历史事实与描述`：40条，含考古、物种、传播、饲养、宫廷与现代文化内容。
- `03_十二生肖`：12条。
- `04_生肖传说`：9条。
- `05_图文信息与来源`：20条。
- `06_数值与时间数据`：9条。

## 数据组织方式
主叙事阶段、朝代子时期、历史事实、专题传说、数值及元数据应拆分存储。保留原始时间文本与标准化时间字段；公元前、约数和“Nowadays”不可按普通数字字符串处理。宏观时期和子时期可能重叠，不能假设所有阶段互斥。

## 数据质量与转换
- 案例001的T02唐宋约600—1300与T03唐618—907、T04宋960—1279为父子层级，不是三条互斥时期。
- T05明清约1300—1900与T06明1368—1644、T07清1644—1912存在概略范围差异。
- 明代皇帝名称在原图与工作簿记录间有冲突，保留原始字段并增加核查标记。
- 记录数仅为工作簿条目，不代表人口或样本量。
