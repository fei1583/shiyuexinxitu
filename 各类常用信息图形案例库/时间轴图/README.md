# 时间轴图案例库

本目录用于收录以时间顺序、事件时点、时间区间或历史阶段组织信息的示例，并从类型学、数据结构、统计图形应用、视觉编码、信息框架和叙事框架等维度持续研究。

## 已收录
- **001｜The history of CATS in China**：主分类为编年型信息图，辅助分类为时间轴图。采用四阶段历史分章，未绘制连续比例时间轴；底部含十二生肖传说专题。[时间轴图案例报告](./02-分析报告/001-The-history-of-CATS-in-China-时间轴图案例分析报告.md)。

## 目录规范
- 示例图放入「01-示例图」。
- 每个案例在「02-分析报告」中单独建立报告。
- 案例积累后，持续修订本目录的六份研究文档。
- 图片由用户自行上传；说明文件不代表二进制文件已进入仓库。
