# 时间轴型信息图形（Timeline Infographics）

以时间轴、事件节点、时间区间、时期分区或并行轨道组织信息，突出事件顺序、时间跨度、阶段演进与历史脉络。编年型为上位叙事分类；时间轴型是常见视觉组织方式。历史阶段分章图可作为非比例时间线变体。
