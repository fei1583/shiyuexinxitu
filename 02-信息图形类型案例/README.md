# 02｜信息图形类型案例：表现形式标签库

**五种基础信息组织逻辑是唯一基础类型学；本目录只负责常见表现形式检索。** 同一表现形式可对应不同基础逻辑，一个作品也可有多个辅助表现标签。

## 17 种表现形式标签

| 编号 | 标签 | 检索特征 | 既有资产交叉入口 |
|---|---|---|---|
| 01 | 混合型 Mixed Charts | 多种图表、符号与叙事组合 | [其他](../各类常用信息图形案例库/其他/) |
| 02 | 文字型／列表型 Informational List | 文字、清单、条目与说明 | [文字型信息图](../各类常用信息图形案例库/文字型信息图/) |
| 03 | 时间轴型 Timeline | 时间刻度、事件与阶段 | [时间轴图](../各类常用信息图形案例库/时间轴图/) |
| 04 | 示意图型 How-to | 操作说明、步骤与教学 | [流程图](../各类常用信息图形案例库/流程图/) |
| 05 | 流程图型 Process | 节点、路径、条件与流向 | [流程图](../各类常用信息图形案例库/流程图/) |
| 06 | 比较型 Comparison | 对照、差异、比例与排名 | [对比图](../各类常用信息图形案例库/对比图/) |
| 07 | 地标／地点型 Location | 地点、区域与空间分布 | [地图](../各类常用信息图形案例库/地图/) |
| 08 | 图片式 Photo-graphic | 照片为主要视觉载体 | 逐案核验后关联 |
| 09 | 层级表现型 Hierarchical | 等级、主次、包含与从属 | [树状图](../各类常用信息图形案例库/树状图/)；[关系图](../各类常用信息图形案例库/关系图/) |
| 10 | 单一图表型 Single Chart | 单一统计图表为主体 | 逐案核验后关联 |
| 11 | 文字可视化 Visualized Text | 文字形态与布局承担编码 | [文字型信息图](../各类常用信息图形案例库/文字型信息图/) |
| 12 | 解剖型 Anatomical | 剖面、部件与内部结构 | [结构图](../各类常用信息图形案例库/结构图/) |
| 13 | 视觉简历 Visual Resume | 经历、技能与履历可视化 | 暂无已确认案例 |
| 14 | 手稿型 Hand-drawn | 手绘线条、手写与草图风格 | 逐案核验后关联 |
| 15 | 编年—编目复合型 Hybrid | 时间序列与类别分组并置 | 逐案核验后关联 |
| 16 | 三维型 3D | 三维空间、立体对象与透视 | [结构图](../各类常用信息图形案例库/结构图/)（需核验） |
| 17 | 词云型 Word Cloud | 词语大小、位置或聚类编码 | [词云图](../各类常用信息图形案例库/词云图/) |

上述标签作为检索框架，不代表每个标签已有合格案例。既有图片、Excel 和分析报告继续保存在「各类常用信息图形案例库」，本目录不复制二进制文件。

每个案例入库时，分别记录：唯一基础主分类、表现形式标签、内容载体、视觉风格、统计图形、基础设计方法、原图来源与版权状态、数据集和分析证据。标签目录中的空白或示意入口不计作正式案例。
