# 文字型/列表型信息图形（Informational / List Infographics）说明文档

> 研究状态：初始框架，须根据后续案例图逐例分析并修订。

## 1. 类型定义与识别边界
以文字条目、标题、短说明、编号/符号和分组结构为主要信息载体，强调快速浏览、知识传递、清单化组织与检索。

## 2. 数据逻辑与结构
通常是条目数组，每项含序号/名称、正文、类别、优先级、标签、图标或来源。可为无序清单、有序步骤、分组目录、检查表或属性卡片。序号可能表达顺序，也可能仅为引用标记，需辨别。

## 3. 统计图形与计算方式
通常不以统计图为核心，可嵌入频数、排名、比例或小型图表。可计算条目数、类别计数、排序、评分或完成比例。若列表顺序有语义，应说明排序依据；不要将视觉编号误作排名。

## 4. 视觉编码方法
文字是主要编码；字号/字重建立层级，编号表达顺序，项目符号表达并列，图标帮助识别，色彩区分类别/状态，卡片/分栏形成分组。确保对比度、行长、留白和可读性。

## 5. 信息架构
常见架构为标题/导语—分组标题—条目（标题+说明）—总结/行动提示—来源。各条目结构尽量平行，控制文字长度；较长清单需提供导航和清晰分组。

## 6. 视觉叙事架构
可采用步骤式（先后操作）、知识点式（并列说明）、问题—建议式或由重要到次要的排序。标题承诺与条目内容应一致；避免把选择性清单包装成完整清单。
