# 混合型信息图形（Mixed Charts）

混合型信息图形并非简单把多个统计图拼在一起，而是将统计图形作为数据证据层，与符号、图标、示意性图形、地图、注释和版面叙事结合，形成面向解释与传播的信息图形。
