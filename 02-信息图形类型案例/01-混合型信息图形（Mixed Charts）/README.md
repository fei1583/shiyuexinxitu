# 混合型信息图形（Mixed Charts）

混合型信息图形将统计图形作为数据证据层，与符号、插画、地图、注释和版面叙事结合，形成复合信息图。

## 已收录案例
- **001｜Power Centers of the Fortune 500**：比例圆点、美国地图、曲线连接与编辑文字组合。[案例报告](./案例分析报告/001-Power-Centers-of-the-Fortune-500-案例分析报告.md)
- **002｜Ageing in Hong Kong**：人物插画、人口比例、18区地图、地区条形图、医疗支出折线图与文字叙事组合。[案例报告](./案例分析报告/002-Ageing-in-Hong-Kong-案例分析报告.md)

两案的地图模块均交叉归档至[常用案例库·地图](../../../各类常用信息图形案例库/地图/README.md)。图片和工作簿统一放入「案例图片」与「案例数据」。
