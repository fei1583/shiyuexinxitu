# 06 视觉编码

## 目标
把数据含义和叙事关系转化为可识别、可比较、可阅读的视觉语言。本阶段偏重设计表达，但每一种视觉选择都应有信息依据。

## 视觉编码要素

### 点、线、面、体
- 点：位置、单体、节点、离散对象。
- 线：路径、时间、连接、流动、关系。
- 面：区域、分类、覆盖范围、分组。
- 体：体量、层次、空间结构；使用时需避免透视造成误读。

### 色彩
建立类别色、数值渐变、强调色和背景色规则。检查色彩对比、色觉差异适配及黑白打印可读性；颜色不应成为唯一编码通道。

### 文字与排版
明确字体层级、字号、字重、行距、字距、对齐、段落节奏、标注密度和阅读顺序。保证标题、正文、注释和图例的层级清晰。

### 图像与图形
选择照片、插画、图标、示意图、地图、流程图、统计图形或其他图形表达。明确图像是证据、对象本身还是装饰，不混淆其作用。

### 统计图形
根据数据类型与比较任务选择条形图、折线图、散点图、比例图、分布图等；注明单位、基线、尺度和必要的误差/不确定性。

### ISOTYPE 图形方法
ISOTYPE 是基础设计方法，不是信息图形类型。若采用，应明确图画符号代表什么、一个符号代表多少、如何重复/分组、图例如何解码，以及符号是否保持一致。
