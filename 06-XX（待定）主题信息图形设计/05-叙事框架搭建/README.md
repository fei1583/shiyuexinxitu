# 05 叙事框架搭建

## 目标
从基础数据集中选择若干字段，组合成明确、可验证、可阅读的叙事主题。

## 字段组合示例
- 名称 + GPS 纬度 + GPS 经度 → 地图上的地点信息。
- 地区名称 + GDP 数值 + 年份 → 某地 GDP 的时空比较。
- 人物名称 + 出生年份 + 关键事件 → 人物或群体的时间叙事。
- 类别名称 + 数量 → 分类构成或规模比较。
- 对象 ID + 上级对象 ID → 层级或关系结构。

## 叙事设计步骤
1. 写出一句话核心命题：这张信息图希望读者理解什么？
2. 确定支撑命题的关键字段和记录范围。
3. 明确字段之间的关系、比较基准和时间/空间尺度。
4. 安排阅读顺序：总览、分组、细节、结论或行动提示。
5. 检查每个视觉元素是否服务于叙事，删除无关信息。
6. 对重要结论进行数据验证，避免因视觉排序造成误导。
