# 08 设计实施

## 目标
将已经确认的研究结论、数据集、叙事框架和视觉编码规范落实为完整的信息图形作品。

## 实施步骤
1. 确认画布尺寸、媒介、输出规格和阅读场景。
2. 建立版式网格、信息层级和视觉动线。
3. 导入经过校验的数据，制作图形、地图、照片/插画和标注。
4. 按视觉编码规范统一色彩、字体、符号、线条和图例。
5. 检查数据准确性、文字准确性、来源标注和版权信息。
6. 进行屏幕/打印等目标媒介的可读性检查。
7. 保存可编辑源文件并导出交付版本。

## 建议目录
- 成品与源文件/：最终导出文件及可编辑源文件。
- 过程稿/：重要版本和设计迭代记录。
- 交付检查.md：最终检查记录。

## 交付检查
- [ ] 主题命题与最终画面一致
- [ ] 数据可追溯，数字与单位准确
- [ ] 图例、比例尺、坐标和注释完整
- [ ] 字体、色彩和图形编码一致
- [ ] 图片/字体/数据许可符合使用要求
- [ ] 屏幕与打印阅读效果通过检查
- [ ] 源文件和导出文件均已归档

## 阶段产出
最终信息图形、可编辑源文件、数据与来源说明、交付检查记录。
