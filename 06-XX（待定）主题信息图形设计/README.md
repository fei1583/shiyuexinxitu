本目录是一套从选题研究到设计交付的主题型信息图形项目工作区。流程强调先理解主题与证据，再建立数据结构和叙事，最后选择视觉编码；不预设项目必须采用某一种信息图形类型或视觉风格。

## 项目基本原则

1. 不先决定图形形式再硬套数据；先研究主题、数据和叙事目标。
2. 类型判断、表现形式、视觉风格和基础设计方法分开记录。
3. 数据来源可追溯；区分原始数据、转录数据、估读数据和推算数据。
4. 基础数据集采用原子字段：**每一列只表达一种数据，每个单元格只放一个数据值**。名义、量化、图像引用和文本均可作为字段值，但不得把多个独立值塞在同一单元格里。
5. 叙事字段组合必须说明其含义，例如“名称 + GPS 坐标”形成地点定位，“地区 + GDP 数值”形成地区经济比较。
6. 视觉编码服务于信息含义和阅读任务，不能只追求装饰效果。
