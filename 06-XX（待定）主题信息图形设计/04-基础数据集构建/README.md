# 04 基础数据集构建

## 核心规则：原子字段

**一列只允许表达一种数据；一个单元格只放一个数据值。** 数据可以是名义数据、量化数据、图像数据引用或文本数据，但不能把多个独立值拼在同一个单元格里。

示例：
- 合适：一列“名称”、一列“纬度”、一列“经度”。
- 不合适：在一个“坐标”单元格里写入“纬度, 经度”两个值；应拆为两列。
- 合适：一列“地区”、一列“GDP数值”、一列“年份”。
- 不合适：把多个年份的 GDP 横向拼成一个文本字段，或把多个地区写进同一单元格。

## 推荐的数据类型
- 名义数据：名称、类别、地区、状态、标签等。
- 量化数据：数量、比例、金额、长度、时间等。
- 图像数据：图像文件路径、稳定资源 ID 或 URL；每个字段只保存一个图像引用。
- 文本文字数据：描述、摘录、注释等；一条记录中的一个字段只承载一个文本值。

## 建议目录
- 数据集/：清洗后的基础数据集（CSV/XLSX）。
- 字段字典.md：字段名称、含义、数据类型、单位、允许值和来源。
- 数据质量检查.md：缺失、重复、异常、格式和来源核验。

## 质量检查
- 每列只有一种字段含义和数据类型。
- 每个单元格只有一个值，不混合多个独立数据。
- 单位统一，日期格式统一，分类值拼写统一。
- 缺失值使用统一表示，不用 0 冒充缺失。
- 每条记录可追溯到来源或采集记录。
- 保留原始数据，不覆盖原件；清洗步骤可复现。
